# Be The Dino 🦖📸

**Be The Dino** is a fun Python-based project where users transform themselves into a dinosaur character by capturing their image using a webcam. A countdown appears, and the captured image can be used as a part of a dinosaur-themed game or visualization.

## 🧩 Features

- Live webcam feed using OpenCV
- Countdown timer with on-screen prompts using Pygame
- Captures and saves a snapshot of the player
- Designed for fun, creative, and interactive gaming experiences

## 📷 How It Works

1. The webcam opens and shows a live feed.
2. A 3-second countdown begins.
3. The player’s image is captured at the end of the countdown.
4. The image can then be used in a game (like becoming the dinosaur player!).

## 🛠️ Technologies Used

- Python 🐍
- OpenCV (`cv2`) for webcam capture
- Pygame for graphics and interface

## 🚀 Getting Started

### Prerequisites

Make sure you have Python 3 installed, then install the required libraries:

```bash
pip install opencv-python pygame
```
Run The Game 
```bash
python adv_dino.py
```
